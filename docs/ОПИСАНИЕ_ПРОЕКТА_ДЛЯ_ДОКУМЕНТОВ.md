# Описание проекта «Для мам» для подготовки документов

Документ предназначен для редакторов и юристов при составлении положения о передаче и обработке персональных данных, пользовательского соглашения и иных правовых документов.

---

## 1. Наименование и назначение проекта

**Название:** «Для мам» (возможные варианты использования: сервис «Для мам», мини-приложение «Для мам», платформа «Для мам»).

**Назначение:** веб-сервис (мини-приложение в мессенджере Telegram), который связывает две категории пользователей:
- **Родителей** — лиц, размещающих заявки на поиск специалистов по уходу за детьми, репетиторству, организации досуга и т.п.;
- **Специалистов** — лиц, оказывающих такие услуги (няни, репетиторы, организаторы досуга и др.).

Сервис позволяет родителям публиковать заявки с описанием потребности, бюджета и района; специалистам — просматривать заявки в ленте, отправлять отклики с ценой и комментарием; родителям — принимать или отклонять отклики, договариваться об условиях и после выполнения работы оставлять друг другу отзывы и оценки. Уведомления о новых откликах и отзывах отправляются пользователям в Telegram.

---

## 2. Способ доступа к сервису

- Сервис доступен **только внутри мессенджера Telegram** в формате Mini App (веб-приложение, открываемое по ссылке из бота).
- Вход и идентификация пользователя выполняются через учётную запись Telegram (авторизация через данные, передаваемые Telegram при запуске мини-приложения). Отдельная регистрация по электронной почте или номеру телефона вне Telegram не предусмотрена.
- Оператор сервиса использует API Telegram для проверки данных авторизации и (при необходимости) для отправки уведомлений пользователям от имени бота.

---

## 3. Категории пользователей и их роли

| Категория | Описание | Основные действия в сервисе |
|-----------|----------|-----------------------------|
| **Родитель** | Пользователь с ролью «Родитель» | Создание заявок, просмотр откликов специалистов, принятие/отклонение откликов, завершение заявок, написание отзывов о специалистах, просмотр анкет специалистов в ленте. |
| **Специалист** | Пользователь с ролью «Специалист» | Просмотр заявок в ленте, просмотр отзывов о заказчиках, отправка откликов на заявки, получение решения по отклику, написание отзывов о родителях, просмотр своих откликов. |

Один пользователь Telegram может иметь несколько «профилей» (ролей): например, одновременно «Родитель» и «Специалист». В каждый момент времени активна одна выбранная роль.

---

## 4. Персональные данные, обрабатываемые в сервисе

### 4.1. Данные, получаемые от Telegram при авторизации

- Идентификатор пользователя в Telegram (telegram id).
- Имя и фамилия (если указаны в аккаунте Telegram).
- Имя пользователя (username) в Telegram.
- Фото профиля (URL изображения, получаемый через API Telegram).

Эти данные используются для создания и обновления учётной записи пользователя в сервисе и для отправки уведомлений в мессенджер.

### 4.2. Данные, вводимые пользователем в сервисе

**Общие для профилей (родитель / специалист):**
- Отображаемое имя (никнейм для показа в заявках и анкетах).
- Пол.
- Возраст.
- Город и район.
- Номер телефона для связи.
- Настройка: показывать ли телефон в анкете и в откликах (да/нет).

**Только для профиля «Родитель»:**
- Возраст детей (список).
- Пожелания к специалисту (произвольный текст).

**Только для профиля «Специалист»:**
- Категория услуг (няня, репетитор, досуг и т.д.).
- Цена за час (руб.).
- Краткое описание о себе (текст).
- При необходимости — фотографии для портфолио (URL хранимых изображений).

**В рамках заявок и откликов:**
- Текст заявки (описание потребности, бюджет, район, даты и т.п.).
- Текст отклика (комментарий специалиста, предложенная цена).
- После завершения сотрудничества — отзыв (оценка по 5-балльной шкале и опционально текст отзыва).

### 4.3. Данные, формируемые в процессе работы сервиса

- Дата и время создания заявок, откликов, отзывов.
- Статусы заявок (активна, в работе, завершена, отменена) и откликов (на рассмотрении, принят, отклонён и т.д.).
- Агрегированный рейтинг пользователя (средняя оценка и количество отзывов) — отображается в анкете и в карточках заявок/откликов.

---

## 5. Цели и способы обработки данных

- **Обеспечение работы сервиса:** идентификация пользователя, ведение профилей и ролей, создание и хранение заявок, откликов и отзывов.
- **Связь сторон:** показ родителям анкет специалистов и откликов с контактными данными (в т.ч. телефон — при согласии специалиста); показ специалистам заявок и отзывов о заказчиках; после принятия отклика — возможность связаться (в т.ч. через Telegram).
- **Информирование пользователей:** отправка в Telegram уведомлений о новом отклике на заявку, о принятии отклика, о новом отзыве (родителям и специалистам).
- **Прозрачность репутации:** отображение рейтинга и отзывов на странице профиля и в карточках заявок/откликов, чтобы пользователи могли оценить надёжность контрагента.

Данные хранятся на серверах оператора в базе данных (PostgreSQL). Передача данных третьим лицам — в объёме, необходимом для работы через Telegram (идентификатор и данные для уведомлений через API Telegram). Явная передача персональных данных другим коммерческим партнёрам для маркетинга или аналитики в описании не предполагается (при изменении политики это должно быть отражено в документах).

---

## 6. Кто видит какие данные

- **Заявки родителей** видят все авторизованные специалисты в ленте (категория, описание, бюджет, район, контактные и демографические данные заказчика в объёме, указанном в его профиле, а также отзывы других специалистов о заказчике).
- **Отклики специалистов** видит родитель — автор заявки (в т.ч. контактный телефон специалиста, если тот разрешил показ).
- **Публичная анкета специалиста** (профиль) доступна по ссылке любому авторизованному пользователю (имя, рейтинг, отзывы, контакты в соответствии с настройками).
- **Отзывы** отображаются на странице профиля того пользователя, о ком они написаны; отзывы о заказчике также показываются в карточке его заявки для специалистов.

Администратор сервиса имеет технический доступ к базе данных для обеспечения работы, резервного копирования и устранения сбоев.

---

## 7. Технические сведения (для справки)

- **Фронтенд:** веб-приложение (React), запускаемое внутри Telegram WebView (Mini App).
- **Бэкенд:** серверное API (NestJS), аутентификация по JWT после проверки данных Telegram.
- **База данных:** PostgreSQL; хранение профилей, заявок, откликов, отзывов, баннеров.
- **Внешние сервисы:** Telegram (авторизация через initData, при необходимости — получение фото профиля; отправка уведомлений через Bot API).
- **Хостинг и инфраструктура:** по усмотрению оператора (указывать в документах при необходимости).
