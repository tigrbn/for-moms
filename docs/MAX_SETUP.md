# Запуск «Для мам» в мессенджере MAX

Мини-приложение «Для мам» поддерживает запуск в **MAX** (наряду с Telegram Mini App). Ниже — что сделано в коде и как подключить приложение к платформе MAX для партнёров.

---

## Что уже сделано в проекте

1. **Бэкенд (API)**
   - При создании сессии принимается параметр `platform: "telegram" | "max"`.
   - Для MAX используется переменная окружения `MAX_BOT_TOKEN` (токен бота, выданный при создании чат-бота в [платформе MAX для партнёров](https://business.max.ru/self)).
   - Валидация `initData` для MAX выполняется по той же схеме, что и для Telegram (HMAC-SHA256, см. [документацию MAX](https://dev.max.ru/docs/webapps/validation)).

2. **Фронтенд (web)**
   - Подключён скрипт MAX Bridge (`max-web-app.js`), доступен глобальный объект `window.WebApp`.
   - При открытии приложения определяется платформа: если есть `window.WebApp.initData` — считаем, что запуск из MAX, иначе — из Telegram.
   - В запрос `/auth/session` передаётся `initData` и `platform`.
   - При готовности приложения вызывается `WebApp.ready()` для MAX (чтобы не показывался экран «нет сети»).

3. **Тексты**
   - Экран входа: «Этот экран работает только внутри Telegram Mini App или мини-приложения MAX.»

---

## Требования к запуску в MAX

- Подключение к платформе MAX для партнёров доступно для **юрлиц и ИП — резидентов РФ**.
- Мини-приложение должно быть доступно по **HTTPS**.
- Рекомендуется хостинг статики (Vercel, GitHub Pages и т.п.) или ваш сервер с SSL.

---

## Переменные окружения на сервере (API)

В `.env` (или в файле с секретами на проде) для работы в MAX добавьте:

```env
MAX_BOT_TOKEN=токен_бота_из_платформы_MAX
```

Токен выдаётся при [создании чат-бота](https://dev.max.ru/docs/chatbots/bots-create) в платформе MAX для партнёров.  
Если `MAX_BOT_TOKEN` не задан, авторизация через MAX будет возвращать ошибку (Telegram продолжит работать с `BOT_TOKEN`).

---

## Подключение мини-приложения в MAX

1. Откройте [платформу MAX для партнёров](https://business.max.ru/self) и перейдите в профиль организации.
2. Если ботов несколько — в левом верхнем углу выберите нужный.
3. Раздел **Чат-бот и мини-приложение → Настроить**.
4. В поле для ссылки вставьте **URL вашего мини-приложения** (тот, по которому открывается веб-приложение по HTTPS).
5. Выберите вид кнопки открытия (Открыть, Старт, Играть или без названия) и нажмите **Сохранить**.

Требования к URL:

- Длина не более 1024 символов.
- Протокол только `https://`.
- Допустимые символы: латиница, цифры, точка (`.`), дефис (`-`). Пробелы не поддерживаются.

Пример: `https://your-domain.com/` или `https://for-moms.vercel.app/`.

После сохранения в чате с ботом появится кнопка для запуска мини-приложения.

## Деплой фронтенда для MAX

Мини-приложение в MAX открывается по одному и тому же URL, что и в браузере/Telegram. То есть:

- Либо вы уже отдаёте фронт с того же домена, что и API (например, nginx раздаёт статику и проксирует `/api` на бэкенд).
- Либо фронт на отдельном домене (Vercel, GitHub Pages), тогда в настройках мини-приложения в MAX укажите этот URL. Убедитесь, что в приложении задан правильный `VITE_API_BASE` (или что запросы к API идут на ваш HTTPS-сервер).

Проверьте, что по выбранному URL приложение открывается по **HTTPS** и что после входа в MAX авторизация проходит (в запросе уходит `platform: "max"` и валидный `initData`).

## Диплинки (deep links)

Открытие мини-приложения по прямой ссылке в MAX:

```text
https://max.ru/<botName>?startapp
```

С параметрами (до 512 символов, символы `A–Z`, `a–z`, `0–9`, `_`, `-`):

```text
https://max.ru/<botName>?startapp=promo_summer2025
```

В приложении параметры доступны через `window.WebApp.initDataUnsafe.start_param` и в строке `window.WebApp.initData` (см. [документацию MAX Bridge](https://dev.max.ru/docs/webapps/bridge)).

---

## Скрипт MAX Bridge

В `web/index.html` подключён скрипт:

```html
<script src="https://static.max.ru/webapp/v1/max-web-app.js" defer></script>
```

Если официальный URL скрипта в документации MAX окажется другим, замените его в `index.html` на актуальный.
