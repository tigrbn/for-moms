# Уведомления разработчику о новых обращениях

Обращения из раздела «Связаться с разработчиком» (сообщить об ошибке / заказать проект) отправляются в Telegram только разработчику.

## Настройка

1. В `api/.env` задайте переменную **TELEGRAM_DEV_CHAT_ID** — числовой ID чата, куда бот будет слать сообщения.

2. Как получить свой chat ID (для профиля tigrbn или любого):
   - Напишите боту [@userinfobot](https://t.me/userinfobot) в Telegram — он пришлёт ваш Id.
   - Либо один раз напишите вашему боту (например, команду /start), затем откройте в браузере:  
     `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates`  
     и найдите в ответе `"chat":{"id": 123456789}` — это и есть TELEGRAM_DEV_CHAT_ID.

3. Перезапустите API после изменения `.env`.

После этого каждое новое обращение из приложения будет приходить вам в личку от бота.
